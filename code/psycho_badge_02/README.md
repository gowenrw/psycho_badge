# psycho_badge_02

First test code for all components on the Psycho Badge.

This code supports both the original GDEM0154F51H EINK display and the
updated GDEM0154F61H EINK display. Set the `display_model` variable near
the top of psycho_badge_02.ino to `EPD_MODEL_51H` or `EPD_MODEL_61H` to
select which panel is installed on the badge.
